# Emmanuel James — Developer Portfolio

A responsive professional portfolio for Emmanuel James.

## Sections
- Hero
- About
- Skills
- Projects
- Services
- Contact

## Tech
HTML, CSS and JavaScript. No build step is required.

## GitHub Pages
Enable **Settings → Pages → Deploy from branch → main → / (root)** to publish the site with GitHub Pages.

Replace the contact form's mail destination in `script.js` with your preferred email address before publishing.
